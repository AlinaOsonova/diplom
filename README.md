# Инструкция по запуску автотестов мобильного приложения «Мобильный хоспис».

## Предварительные требования

Перед началом работы убедитесь, что установлены:
- **Android Studio** (последняя стабильная версия).
- **Git** для клонирования репозитория.
- **Allure** для генерации отчетов.
- **Java JDK** (версия 11 или выше).

## Пошаговая инструкция

### Шаг 1: Клонирование проекта

Откройте терминал (командную строку) и выполните команду для клонирования репозитория:

git clone https://github.com/AlinaOsonova/diplom.git. Дождитесь завершения клонирования.

### Шаг 2: Открытие проекта в Android Studio

1. Запустите Android Studio.
2. Откройте склонированный проект.
5. Дождитесь завершения индексации и синхронизации проекта (Gradle Sync).

### Шаг 3: Запуск Gradle сборки проекта

Выполните сборку проекта.

### Шаг 4: Запуск эмулятора через Device Manager

В Android Studio откройте Device Manager и создайте новый эмулятор API 29 (Android 10).

### Шаг 5: Запуск тестов

Правой кнопкой мыши нажмите на папку `tests` → `Run ` или через командную строку.

### Шаг 6: Копирование результатов тестов с эмулятора

После завершения тестов необходимо скопировать результаты Allure с устройства.

### Шаг 7: Генерация HTML-отчета

1. Добавьте `allure-results` в корень проекта.

3. Запустите команду в терминале для просмотра отчета: allure serve.

3. Отчет автоматически откроется в браузере.
